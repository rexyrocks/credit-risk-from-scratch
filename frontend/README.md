# Credit Risk Predictor — Frontend

React + Vite + Tailwind CSS v4 frontend for the Credit Risk Prediction web app.

See [WEBAPP.md](../WEBAPP.md) in the project root for full setup instructions.

## Development

```bash
npm install
npm run dev
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `VITE_API_URL` | `http://localhost:8000` | URL of the FastAPI backend |
